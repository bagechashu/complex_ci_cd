下面给你一个**工程可执行的实施计划（按阶段拆解 + 明确交付物）**。目标是：在最短时间内上线一个**可用、可控、可追溯**的发布系统，同时为后续演进预留结构。

# 一、总体目标（边界清晰）

**本期（MVP）只解决：**

* 多环境 / 多集群发布
* 多 workload 名差异
* 多 harbor（仅 domain 不同）
* 支持 K8s 发布（优先）
* 提供统一发布入口（API + 简单前端）

**明确不做：**

* GitOps（ArgoCD）
* 自动环境同步
* 复杂审批流
* 全量 Jenkins 替换

---

## 1️⃣ 数据库设计（SQLite）

### 必须实现的表

```sql
-- 应用
CREATE TABLE application (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    repo TEXT,
    build_type TEXT
);

-- 环境
CREATE TABLE environment (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    type TEXT
);

-- 集群
CREATE TABLE cluster (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    type TEXT NOT NULL,
    kubeconfig TEXT
);

-- 部署目标（核心）
CREATE TABLE workload_target (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    app_id INTEGER,
    env_id INTEGER,
    cluster_id INTEGER,

    k8s_namespace TEXT,
    k8s_workload TEXT,
    container_name TEXT,

    registry_domain TEXT,
    image_repo TEXT,

    UNIQUE(app_id, env_id, cluster_id)
);
```

## 4️⃣ 核心逻辑（ReleaseService）

```go
func Release(appID, envID, clusterID int64, tag string) error {
    target := repo.Get(appID, envID, clusterID)

    image := fmt.Sprintf("%s/%s:%s",
        target.RegistryDomain,
        target.ImageRepo,
        tag,
    )

    return k8sDeployer.Deploy(target, image)
}
```
