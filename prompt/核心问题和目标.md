当前系统的发布链路因历史演进呈现出明显的碎片化：不同环境使用不一致的 Kubernetes 集群、namespace 与 deployment 命名规则，同一应用在多个环境下需要构建和分发多份镜像；同时 Harbor registry 存在多域名差异，导致镜像地址无法统一；发布路径也分裂为 Jenkins + K8s、Salt 部署 JAR、Ansible 批量脚本等多种模式，缺乏统一抽象与控制面，造成流程复杂、易出错且难以维护。在时间紧迫的前提下，亟需建立一个基于 Golang（go-chi）与 Vue3 的轻量级发布控制系统，通过统一 Application 逻辑模型、引入 DeploymentTarget 与 Cluster 映射，将环境差异完全配置化，收敛多集群、多部署方式与多 registry 的复杂性，最终实现开发人员可自助选择目标环境与版本标签，一键完成构建与发布，并具备可追踪、可回滚的标准化发布能力。
