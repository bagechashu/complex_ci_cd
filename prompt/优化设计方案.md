# 🚀 优化设计方案 v2.0

> 在原架构设计基础上，优化数据模型、系统抽象、生命周期管理、安全审计体系

---

## 📋 核心优化方向

| 优化项 | 原设计问题 | 改进方案 |
|------|---------|--------|
| **数据模型** | release_record 被延后到第二阶段 | 纳入MVP，实现发布全生命周期追踪 |
| **部署抽象** | 仅提到K8s实现，多种部署方式没有统一接口 | 定义Deployer策略接口，支持即插即用 |
| **发布流程** | 缺少验证和状态管理 | 明确的状态机（pending→validating→deploying→success/rollback） |
| **安全审计** | 权限本来是第二阶段 | 从MVP就记录操作者和操作时间 |
| **前端交互** | 过于简化，缺少反馈 | 实时进度、错误提示、历史快速回滚 |
| **kubeconfig管理** | 加密被推到第二阶段 | MVP就实现最小化加密存储 |

## 一、优化的数据库设计（SQLite）

### 表结构设计（完整版）

```sql
-- 应用（应用元信息）
CREATE TABLE application (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    repo TEXT,                    -- Git仓库地址
    build_type TEXT,              -- docker / jar / bin（构建类型）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 环境（逻辑环境）
CREATE TABLE environment (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,    -- prod / staging / dr
    rank INTEGER,                 -- 环保等级（用于权限）：1=prod, 2=staging, 3=dev
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 集群（物理集群）
CREATE TABLE cluster (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    type TEXT NOT NULL,           -- kubernetes / salt / ansible
    kubeconfig_encrypted TEXT,    -- AES加密存储（仅K8s）
    salt_master_url TEXT,         -- Salt Master地址（仅Salt）
    ansible_inventory TEXT,       -- Ansible Inventory（仅Ansible）
    enabled BOOLEAN DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 部署目标（核心映射表）
CREATE TABLE deployment_target (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    app_id INTEGER NOT NULL,
    env_id INTEGER NOT NULL,
    cluster_id INTEGER NOT NULL,
    
    -- K8s特定字段
    k8s_namespace TEXT,
    k8s_deployment TEXT,          -- deployment/statefulset/daemonset等
    container_name TEXT,          -- 明确容器名，防止误更新sidecar
    
    -- Harbor配置
    registry_domain TEXT,         -- harbor.example.com
    image_repo TEXT,              -- project/service
    
    -- 部署策略（新增）
    deploy_strategy TEXT DEFAULT 'RollingUpdate',  -- RollingUpdate / BlueGreen / Canary
    max_surge TEXT DEFAULT '1',   -- K8s滚动更新参数
    max_unavailable TEXT DEFAULT '0',
    
    -- Salt/Ansible特定字段
    salt_target TEXT,             -- 目标minion ID（仅Salt）
    ansible_host_group TEXT,      -- 主机组（仅Ansible）
    
    enabled BOOLEAN DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(app_id, env_id, cluster_id)
);

-- 发布记录（MVP必须，完整生命周期）
CREATE TABLE release_record (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    app_id INTEGER NOT NULL,
    env_id INTEGER NOT NULL,
    cluster_id INTEGER NOT NULL,
    
    -- 发布内容
    image TEXT NOT NULL,          -- registry/repo:tag
    target_replicas INTEGER,      -- 期望副本数（用于验证）
    
    -- 生命周期
    status TEXT NOT NULL,         -- pending / validating / deploying / success / failed / rolled_back
    started_at DATETIME,
    completed_at DATETIME,
    
    -- 审计信息
    operator TEXT NOT NULL,       -- 操作者（从JWT/Header获取）
    request_id TEXT UNIQUE,       -- 链路追踪ID
    
    -- 错误追踪
    error_msg TEXT,               -- 失败原因
    error_stack TEXT,             -- 错误堆栈
    
    -- 回滚关系
    previous_release_id INTEGER,  -- 指向上一次成功发布
    
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (app_id) REFERENCES application(id),
    FOREIGN KEY (env_id) REFERENCES environment(id),
    FOREIGN KEY (cluster_id) REFERENCES cluster(id),
    FOREIGN KEY (previous_release_id) REFERENCES release_record(id)
);

-- 发布事件日志（详细追踪）
CREATE TABLE release_event (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    release_id INTEGER NOT NULL,
    
    event_type TEXT NOT NULL,     -- request_received / validation_start / validation_pass / deployment_start / pod_updated / rollout_complete / error
    event_message TEXT,
    event_data TEXT,              -- JSON格式的事件详情
    
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (release_id) REFERENCES release_record(id)
);

-- 操作日志（审计）
CREATE TABLE audit_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    operator TEXT NOT NULL,
    action TEXT NOT NULL,         -- release / rollback / config_change
    resource_type TEXT,           -- application / deployment_target / cluster
    resource_id INTEGER,
    
    old_value TEXT,               -- JSON备份（config_change时）
    new_value TEXT,
    
    ip_address TEXT,
    success BOOLEAN,
    error_msg TEXT,
    
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 索引优化
CREATE INDEX idx_release_app_env ON release_record(app_id, env_id);
CREATE INDEX idx_release_created ON release_record(created_at DESC);
CREATE INDEX idx_release_status ON release_record(status);
CREATE INDEX idx_event_release ON release_event(release_id);
CREATE INDEX idx_audit_operator ON audit_log(operator);
CREATE INDEX idx_audit_created ON audit_log(created_at DESC);
```

## 二、统一的发布架构（支持多种部署方式）

### 2.1 部署接口抽象

```go
// internal/deploy/deployer.go

package deploy

import "context"

// DeployStrategy 定义统一的部署策略接口
type DeployStrategy interface {
    // Deploy 执行部署
    Deploy(ctx context.Context, req DeployRequest) (*DeployResult, error)
    
    // Validate 部署前验证
    Validate(ctx context.Context, req DeployRequest) error
    
    // Rollback 回滚到上一个版本
    Rollback(ctx context.Context, req RollbackRequest) error
    
    // Status 查询部署状态
    Status(ctx context.Context, req StatusRequest) (*DeployStatus, error)
    
    // HealthCheck 部署后的健康检查
    HealthCheck(ctx context.Context, req HealthCheckRequest) (bool, error)
    
    // Type 返回部署类型标识
    Type() string
}

// DeployRequest 统一部署请求
type DeployRequest struct {
    Target        *DeploymentTarget  // 部署目标配置
    Image         string             // 新镜像
    PreviousImage string             // 上一个镜像（用于回滚对比）
    Operator      string             // 操作者
    RequestID     string             // 链路追踪ID
}

// DeployResult 部署结果
type DeployResult struct {
    Success      bool
    Message      string
    StartTime    time.Time
    EndTime      time.Time
    EventsLog    []EventLog
}

// EventLog 事件日志
type EventLog struct {
    Type      string    // validation_passed / rollout_started / pod_updated / error
    Message   string
    Data      interface{}
    Timestamp time.Time
}

// RollbackRequest 回滚请求
type RollbackRequest struct {
    ReleaseID   int64
    Operator    string
    RequestID   string
}

// StatusRequest 查询状态请求
type StatusRequest struct {
    ReleaseID int64
}

// DeployStatus 部署状态
type DeployStatus struct {
    Status        string    // pending / deploying / success / failed
    UpdatedTime   time.Time
    Message       string
    PodsReady     int
    PodsTotal     int
    ProgressPct   int       // 0-100
}

// HealthCheckRequest 健康检查请求
type HealthCheckRequest struct {
    Target *DeploymentTarget
    Image  string
}
```

package deploy

import "fmt"

// DeployerFactory 根据集群类型创建部署器
type DeployerFactory struct {
    k8sDeployer      DeployStrategy
    saltDeployer     DeployStrategy
    ansibleDeployer  DeployStrategy
}

func NewDeployerFactory() *DeployerFactory {
    return &DeployerFactory{
        k8sDeployer:     NewK8sDeployer(),
        saltDeployer:    NewSaltDeployer(),
        ansibleDeployer: NewAnsibleDeployer(),
    }
}

// Create 获取对应的部署器
func (f *DeployerFactory) Create(clusterType string) (DeployStrategy, error) {
    switch clusterType {
    case "kubernetes":
        return f.k8sDeployer, nil
    case "salt":
        return f.saltDeployer, nil
    case "ansible":
        return f.ansibleDeployer, nil
    default:
        return nil, fmt.Errorf("unsupported cluster type: %s", clusterType)
    }
}

### 3.2 ReleaseService核心逻辑

```go
// internal/service/release_service.go

package service

import (
    "context"
    "fmt"
    "time"
    
    "your-module/internal/deploy"
    "your-module/internal/model"
    "your-module/internal/repository"
)

type ReleaseService struct {
    repo        repository.ReleaseRepository
    deployer    deploy.DeployerFactory
    registry    RegistryClient // 镜像验证
}

func (s *ReleaseService) Release(ctx context.Context, req ReleaseRequest) (*ReleaseResponse, error) {
    const requestID = "req_" + UUID() // 链路追踪ID
    
    // 1️⃣ 参数验证
    if err := s.validateRequest(req); err != nil {
        return nil, fmt.Errorf("invalid request: %w", err)
    }
    
    // 2️⃣ 获取部署目标
    target, err := s.repo.GetDeploymentTarget(req.AppID, req.EnvID, req.ClusterID)
    if err != nil {
        return nil, fmt.Errorf("deployment target not found: %w", err)
    }
    
    // 3️⃣ 镜像构建
    image := fmt.Sprintf("%s/%s:%s", target.RegistryDomain, target.ImageRepo, req.Tag)
    
    // 4️⃣ 镜像验证（第一扇形门）
    if err := s.registry.ValidateImage(ctx, image); err != nil {
        return nil, fmt.Errorf("image validation failed: %w", err)
    }
    
    // 5️⃣ 创建发布记录（状态 = validating）
    releaseRecord := &model.ReleaseRecord{
        AppID:     req.AppID,
        EnvID:     req.EnvID,
        ClusterID: req.ClusterID,
        Image:     image,
        Status:    "validating",
        Operator:  req.Operator,
        RequestID: requestID,
        StartedAt: time.Now(),
    }
    
    releaseID, err := s.repo.CreateReleaseRecord(releaseRecord)
    if err != nil {
        return nil, fmt.Errorf("failed to create release record: %w", err)
    }
    
    // 6️⃣ 获取Deployer实例
    strategyImpl, err := s.deployer.Create(target.Cluster.Type)
    if err != nil {
        s.recordFailure(releaseID, "failed to get deployer", err)
        return nil, err
    }
    
    // 7️⃣ 前置验证（deployer级别验证）
    deployReq := &deploy.DeployRequest{
        Target:    target,
        Image:     image,
        Operator:  req.Operator,
        RequestID: requestID,
    }
    
    if err := strategyImpl.Validate(ctx, *deployReq); err != nil {
        s.recordFailure(releaseID, "deployer validation failed", err)
        return nil, fmt.Errorf("deployer validation failed: %w", err)
    }
    
    // 8️⃣ 更新状态 → deploying
    s.repo.UpdateReleaseStatus(releaseID, "deploying")
    s.recordEvent(releaseID, "deployment_started", "deployment process started")
    
    // 9️⃣ 异步执行部署
    go s.deployAsync(ctx, releaseID, target, strategyImpl, deployReq)
    
    // 🔟 返回响应 (207 Accepted，表示异步执行中)
    return &ReleaseResponse{
        ReleaseID: releaseID,
        Status:    "accepted",
        Message:   "deployment in progress",
        RequestID: requestID,
    }, nil
}

// 异步部署
func (s *ReleaseService) deployAsync(
    ctx context.Context,
    releaseID int64,
    target *model.DeploymentTarget,
    strategy deploy.DeployStrategy,
    req *deploy.DeployRequest,
) {
    deployCtx, cancel := context.WithTimeout(ctx, 5*time.Minute)
    defer cancel()
    
    // 执行部署
    result, err := strategy.Deploy(deployCtx, *req)
    
    if err != nil {
        s.recordAsyncFailure(releaseID, err, result)
        return
    }
    
    // 记录事件日志
    for _, event := range result.EventsLog {
        s.recordEvent(releaseID, event.Type, event.Message)
    }
    
    // 健康检查
    healthcheckReq := &deploy.HealthCheckRequest{
        Target: target,
        Image:  req.Image,
    }
    
    if healthy, err := strategy.HealthCheck(deployCtx, *healthcheckReq); !healthy || err != nil {
        s.recordAsyncFailure(releaseID, fmt.Errorf("health check failed"), nil)
        return
    }
    
    // 更新最终状态 → success
    s.repo.UpdateReleaseRecord(releaseID, map[string]interface{}{
        "status":       "success",
        "completed_at": time.Now(),
    })
    s.recordEvent(releaseID, "rollout_complete", "deployment completed successfully")
}

// 回滚
func (s *ReleaseService) Rollback(ctx context.Context, req RollbackRequest) error {
    // 查询上一次成功发布
    previousRelease, err := s.repo.GetPreviousSuccessfulRelease(req.ReleaseID)
    if err != nil {
        return fmt.Errorf("no previous release found")
    }
    
    // 获取部署目标
    target, err := s.repo.GetDeploymentTarget(
        previousRelease.AppID,
        previousRelease.EnvID,
        previousRelease.ClusterID,
    )
    if err != nil {
        return err
    }
    
    // 创建回滚记录
    rollbackRecord := &model.ReleaseRecord{
        AppID:              req.ReleaseID,
        Image:              previousRelease.Image,
        Status:             "rolling_back",
        Operator:           req.Operator,
        PreviousReleaseID:  previousRelease.ID,
        StartedAt:          time.Now(),
    }
    
    rollbackID, _ := s.repo.CreateReleaseRecord(rollbackRecord)
    
    // 执行回滚
    strategy, _ := s.deployer.Create(target.Cluster.Type)
    rollbackReq := &deploy.RollbackRequest{
        ReleaseID: req.ReleaseID,
        Operator:  req.Operator,
    }
    
    if err := strategy.Rollback(ctx, *rollbackReq); err != nil {
        s.recordAsyncFailure(rollbackID, err, nil)
        return err
    }
    
    return nil
}
```

## 五、MVP 阶段优化总结

### 5.1 改进的表结构

| 改进项 | 原设计 | 优化版 |
|------|------|-------|
| 生命周期追踪 | 仅有image/status/created_at | 完整的status状态机 + 事件日志+ 时间戳 |
| 审计信息 | 无 | operator + request_id + 审计日志表 |
| 部署策略 | 仅K8s | 支持deploy_strategy + 参数化(max_surge等) |
| 多部署方式 | 仅K8s字段 | K8s/Salt/Ansible的配置字段并存 |
| 数据关联 | 无 | release_event追踪细node级变化 |

### 5.2 改进的架构抽象

```
原设计:  Deploy(target, image) 单一函数

优化设计:
  - DeployStrategy 接口（可扩展多种部署方式）
  - Validate() 前置验证
  - Rollback() 原生回滚支持
  - HealthCheck() 验证部署结果
  - Status() 实时查询进度
  - 完整事件日志（可用于前端实时更新）
```

### 5.3 改进的前端交互

```
原设计:  单一页面 → 选择+发布，无反馈

优化设计:
  1. 发布选择页面
     - 下拉选择 app/env/cluster
     - 动态加载镜像tag列表（可选）
     - 显示上次发布信息
  
  2. 发布进度页面
     - 实时展示status变化（轮询或WebSocket）
     - 事件日志流（deployment_started / pod_updated / etc）
     - 预计完成时间
     - 错误提示（如果失败）
  
  3. 发布历史页面
     - 列表展示最近20次发布
     - 一键回滚按钮
     - 镜像对比（当前版本 vs 上一版本）
```

### 6.1 kubeconfig加密

```go
// internal/crypto/encryption.go

type Encryptor interface {
    Encrypt(plaintext []byte) (ciphertext []byte, err error)
    Decrypt(ciphertext []byte) (plaintext []byte, err error)
}

// 使用AES-GCM加密
func (e *AESEncryptor) Encrypt(plaintext []byte) ([]byte, error) {
    block, _ := aes.NewCipher(e.key) // 256位密钥
    aead, _ := cipher.NewGCM(block)
    
    nonce := make([]byte, aead.NonceSize())
    io.ReadFull(rand.Reader, nonce)
    
    ciphertext := aead.Seal(nonce, nonce, plaintext, nil)
    return ciphertext, nil
}

// 存储时
kubeconfig_encrypted = encryptor.Encrypt([]byte(kubeconfig))

// 使用时
kubeconfig_decrypted = decryptor.Decrypt(cluster.KubeconfigEncrypted)
```

| **错误处理** | 标准HTTP错误 | 完整错误码体系+详细上下文 |
| **可扩展性** | 难 | 设计模式支持直接扩展（Salt/Ansible等） |

这是一个**生产级别的发布系统设计**，既保持了MVP的快速交付，又为后续演进预留了充分的结构空间。
